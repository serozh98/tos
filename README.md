# Сбор глав китайской книги

Небольшой проект для исследования **《穿书反派，圣女小姐别偷听》** (автор **鱼鱼没睡醒**). Источник проверки: [Shuhaige, книга 360588](https://m.shuhaige.net/360588/). По стороннему каталогу Douluobook упоминаются 232 главы, но это **не** означает, что все RAW-главы доступны и проверены.

## English MTL — FanMTL 1239043

Добавлен отдельный сборщик для **航海：吾乃世界最强生物** (английские главы **Sailing: I Am The Strongest Creature In The World**, 1–234 по оглавлению FanMTL). Он не связан с Shuhaige.

- [Скрипт FanMTL](tools/novel_ingest/fanmtl_collect.py) и [документация](docs/fanmtl-1239043.md).
- [GitHub Actions — проверка и выгрузка](.github/workflows/fanmtl-1239043.yml).
- По умолчанию: проверка каталога и (в PR) одной главы без сохранения текста. **0 сохранённых глав**.
- На GitHub Actions **Wuxiabox прошёл проверку главы №55**, FanMTL возвращает HTTP 403. При автоматической проверке PR используется Wuxiabox; другой источник можно выбрать вручную.
- Сохранение полного англоязычного текста только при явном подтверждении прав и только в краткосрочный артефакт; публичный коммит с текстами не создаётся.
- Первая предлагаемая партия MTL для проверки: **55–58**. Отдельно от наших русских переводов, которые ведутся партиями по четыре главы.

## Что делает

- Читает оглавление, включая дополнительные страницы, и связывает номера с настоящими ссылками (не угадывает адреса глав).
- По запросу проверяет и сохраняет главами **1–10 за запуск**, включая вторые страницы главы, если они есть.
- Не сохраняет страницы ошибок, блокировки, неверных глав и подозрительно короткие тексты.
- Создаёт файл manifest.json с URL, числом знаков, SHA-256 и статусом **каждой** запрошенной главы, а также summary.md.
- Не переводит текст и не синхронизирует Notion; эти этапы выполняются отдельно.

## Запуск через GitHub

1. Откройте вкладку [Actions](../../actions/workflows/shuhaige-chapters.yml).
2. Выберите **Collect Chinese book chapters (Shuhaige 360588)** → **Run workflow**.
3. Укажите start и end (максимум 10 глав за запуск).
4. По умолчанию запускается **только сбор оглавления**. Если у вас есть необходимые права на тексты и нужно сохранить RAW, включите **save_text** и **rights_confirmed**.
5. По завершении скачайте вложение shuhaige-360588-audit из запуска. Срок хранения результатов — 7 дней.

## Локальный запуск

~~~bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v

# Только оглавление и технический отчёт
python tools/novel_ingest/shuhaige_collect.py --start 1 --end 5 --out-dir out/catalog

# Только при наличии прав на получение и хранение текста
python tools/novel_ingest/shuhaige_collect.py --start 1 --end 3 --save-text --rights-confirmed --out-dir out/chapters
~~~

## Что означают результаты

- **CATALOG_ONLY** — получено оглавление, **0 RAW-глав сохранено**.
- **PASS** — каждый номер запрошенного диапазона сохранён с проверкой текста.
- **PARTIAL** — есть недостающие, закрытые или повреждённые главы. Не считайте диапазон полным.
- **BLOCKED / CATALOG_ERROR** — оглавление недоступно или не прошло проверку.

**Ограничения:** честный User-Agent, проверка robots.txt, пауза не меньше 2 секунд, только HTTPS-домен Shuhaige, отсутствие авторизации, обходов защиты, подмены браузера и автоматических повторов заблокированных запросов. Тексты не добавляются в публичный репозиторий, а вывод складывается в краткосрочный артефакт запуска. Используйте только при наличии необходимых прав и в рамках условий сайта. Shuhaige — сторонний источник; **первоисточник автора и связь с Rulate № 200365 ещё не подтверждены**.
