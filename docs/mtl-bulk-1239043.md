# Wuxiabox MTL 1239043: sequential collection of chapters 55-234

Book: 航海：吾乃世界最强生物. English MTL source: Wuxiabox.

## How to start the job

The repository contains tools/novel_ingest/mtl_bulk_1239043.py and
.github/workflows/mtl-bulk-1239043.yml.

1. Explicitly confirm necessary rights to obtain and store the English MTL.
2. Create or update runs/mtl-1239043-collection.json on branch main.
3. The scoped GitHub push event runs offline tests and then the collector.
4. Find the run under Actions > MTL 1239043 - sequential authorized collection.
5. Download the artifact mtl-1239043-english-55-234. It contains English TXT
   files, manifest.json with per-chapter hashes/status, and summary.md.
   GitHub retains the artifact for 3 days. In a public repo, artifacts
   may be accessible to other users.

Sample request file:
{
  "book": "航海：吾乃世界最强生物",
  "source": "wuxiabox",
  "start": 55,
  "end": 234,
  "delay_seconds": 3.0,
  "rights_confirmed": true
}

## Site-friendly behavior

- One HTTP session, one cached catalog, one robots.txt request, one sequential
  GitHub Actions job. Never fetch chapters concurrently.
- At least 3 seconds between all HTTP requests, including catalog and chapters.
  Honor higher crawl-delay values specified in robots.txt.
- Internally group results into batches of 10, but do not fetch them in parallel.
- Stop after a batch with missing/invalid content, blocked access, HTTP 403,
  HTTP 429, robots.txt disallow, or network error. No automated retry,
  source switching, authentication workaround or proxy rotation.
- Each saved chapter is validated and hashed with SHA-256.
- The script stores text only in the job artifact, not in the public git tree.
- A successful download is not a verification against the Faloo Chinese RAW
  and does not mean any Russian chapters have been translated.

If the run ends with PARTIAL, inspect the last SAVED file and error statuses;
any later new run should begin strictly AFTER the last saved chapter to avoid
unnecessary duplicate requests.
