# Сбор английских MTL-глав — Faloo 1239043

Книга: **航海：吾乃世界最强生物** / *Sailing: I Am The Strongest Creature In The World*. Автор оригинала: 灌砼高手. Основной источник китайского текста: [Faloo](https://wap.faloo.com/1239043.html). Для **вспомогательного** машинного перевода на английский найдено [оглавление FanMTL](https://www.fanmtl.com/novel/sailing-i-am-the-strongest-creature-in-the-world.html). Там перечислено 234 главы; факт наличия каждой полной главы пока отдельно не установлен.

Наш проект перевода и реестр RAW/RU — в [Notion](https://app.notion.com/p/3f7e1972e97281319559c5cbfde8db0f). Уже получены китайские RAW 001–054 от владельца проекта и созданы русские черновики 001–004. Английский MTL **не является китайским оригиналом и не переводится автоматически на русский**.

## Назначение

- Проверить общедоступное оглавление и фактически видимые номера.
- Для **конкретного разрешённого диапазона** сохранить английские MTL-главы с правильными номерами и заголовками, один UTF-8 TXT на номер.
- Создать `manifest.json` и `summary.md`: реальный результат, исходный URL, длина, SHA-256, пропуски и причины ошибок. Не подменять ошибки содержимым соседней главы.
- Использовать прямую схему URL `_N.html`, подтверждая **по содержимому страницы** название произведения и номер главы. Само наличие URL не считается подтверждённым RAW.
- Не добавлять тексты в GitHub-коммиты или Notion автоматически; вложение GitHub Actions хранится **3 дня**, и в открытом репозитории оно может быть доступно другим пользователям.

## Через GitHub Actions

После появления файла сценария в ветке `main`: [FanMTL 1239043 — запуски](../.github/workflows/fanmtl-1239043.yml).

1. Открыть **Actions** → **FanMTL 1239043 - audit / collect chapters** → **Run workflow**.
2. Указать `start` и `end`, например **55** и **58**. За один запуск от **1 до 10** последовательных глав.
3. Если нужно проверить доступ к каталогу и номера без загрузки глав, оставить `save_text = false` (по умолчанию).
4. Для сохранения полного англоязычного текста включить **оба** параметра: `save_text = true` и `rights_confirmed = true` — только при наличии необходимых прав на получение и хранение этих текстов.
5. После выполнения открыть **Summary** и скачать вложение с отчётом (и, если разрешено, TXT).

Через **чат**: новый commit в ветку открытого PR создаёт событие `pull_request:synchronize`. Сценарий на PR **запускает лишь проверки кода и проверку публичного оглавления**, никаких полных глав не сохраняет. Это не прямой `workflow_dispatch`. До объединения сценария с `main` ручной запуск через меню Actions может быть недоступен.

## Локальный запуск

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v

# Без сохранения полных глав, только каталог
python tools/novel_ingest/fanmtl_collect.py --start 55 --end 58 --out-dir out/audit

# Только при наличии необходимых прав
python tools/novel_ingest/fanmtl_collect.py --start 55 --end 58 --save-text --rights-confirmed --out-dir out/55-58
```

Содержание архива после разрешённой текстовой проверки:

```text
out/55-58/
  manifest.json
  summary.md
  mtl_en/
    0055.txt
    0056.txt
    0057.txt
    0058.txt
```

## Статусы

- `CATALOG_ONLY`: прочитано оглавление, **0 текстов**.
- `PASS`: все запрошенные главы фактически сохранены.
- `PARTIAL`: получена лишь часть глав или возникла ошибка.
- `NETWORK_ERROR`: нет сетевого соединения.
- `BLOCKED`, `ROBOTS_DISALLOWED`: ограничения доступа; **повторов и обходов нет**.
- `CATALOG_ERROR`: не удалось надёжно распознать оглавление.

Скрипт не использует учётные записи, обход CAPTCHA, платный контент, смену прокси или скрытые API сайта. Запросы идут по HTTPS, с уважением к `robots.txt` и с задержкой не менее **3 секунд**. Если сайт изменит структуру, он выдаст ошибку вместо заведомо неверного текста. **Текущая реальная доступность сайта с GitHub Actions требует проверки:** автономные тесты не доказывают успешного скачивания.

Если MTL-главы 55–234 доступны и сохранены, это **не означает**, что китайские RAW-главы получены или что русские переводы готовы. Не увеличивать счётчики RAW/RU без самостоятельной сверки.
